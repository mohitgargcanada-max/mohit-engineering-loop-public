  reviewer. Every backend builder's work needs a native Claude or Codex inspection before ready.
  Plan approval also needs a native reviewer.

  optional capacity note on handoffs.

  standards, who decides the builder, and how standards change. A pre-authorized fallback ladder replaces
  "wait for the quota reset", still never silent.
