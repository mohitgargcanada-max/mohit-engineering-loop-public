## Accepted scope

- C1 Attribution: every authorship declaration records label, model and the files changed since the last
  record, in an append-only task ledger. `show --who` lists who touched which files.
- C2 Scope guard (anti-drift): a plan may declare path scope (`init --scope GLOB`, repeatable). A declared
  change outside it is refused unless the owner records `--outside-scope REASON`.
- C3 Mistake ledger and bench: confirmed findings are attributed to the label+model that built the code, in a
  global roster (default `~/.mel/roster.jsonl`, `MEL_ROSTER` overrides it so CRISP can point it into the
  vault). A model that crosses the bench threshold (default: 2 high, or 4 high+medium, within its last 10
  attributed tasks) is refused as a builder until a recorded user override or the window clears.
- C4 Evals for complex work: `init --risk high` requires a rubric eval report (judge native, not the builder's
  provider, every criterion at or above its threshold) before `ready`. Normal-risk tasks skip it.
- C5 Round budget: plan reviews and inspections are counted; going past the plan's budget needs a recorded
  reason (`--extend REASON`).
- C6 Context packet: `show --brief` prints a compact, stable resume packet (goal pointer, open criteria,
  constraints, scope, last findings, next action) for agents and resumed sessions. This is the "own cache":
  reuse a small stable prefix instead of re-reading history.
- C7 Docs: `references/discipline.md` (guardrails drawn from the owner's project and CRISP practice that proved itself),
  `references/context.md` (token efficiency and prompt caching: documented Claude Code settings, stable-prefix
  rules, why no mod can change the request), SKILL.md pointers, VALIDATION.
- C8 Suite and validator pass locally and in CI, draft PR, Codex plan review and final inspection, installed
  for both hosts with backups.
